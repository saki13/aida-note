# 变更日志（Change Log）模板

> 版本：v0.1.0
> 资产归类：产品资产 -> 标准模板
> 作用：定义每个项目的变更日志实例结构。Aida 按本模板 + [T3 变更管理规则](../rules/T3_变更管理规则_待确认.md) 生成项目级 `change_log.md`（建设资产）。
> 上级文档：[AidaPulse 白皮书 v0.1.0](../whitepaper/AidaPulse白皮书_待确认.md)

---

## 0. 模板定位

变更日志记录项目中所有**正式变更**的完整生命周期（发起 → 评估 → 批准 → 同步 → 关闭）。它是 T3 变更管理规则的落地实例，与 `evolution_log.md` 平行但分工不同：change_log 记「变更流水」，evolution_log 记「框架演进节点」。

---

## 最小可用模板（占位符）

```md
# 变更日志（Change Log）

> 用途：记录项目中所有正式变更的完整生命周期（发起->评估->批准->同步->关闭）。
> 规则依据：{相对路径}/product/rules/T3_变更管理规则_待确认.md
> 维护者：Aida v0.1.0

---

## 变更记录

*暂无变更记录。*

---

*文件创建：{YYYY-MM-DD} | Aida v0.1.0*
```

---

## 单条变更记录格式（追加用）

```md
### {变更ID} · {YYYY-MM-DD} · {变更摘要}

| 字段 | 内容 |
|------|------|
| 发起人 | {PO / Agent / Aida} |
| 风险等级 | 低 / 中 / 高 |
| 评估结论 | {评估依据} |
| 批准人 | {PO / Aida（低风险+短 Sprint）} |
| 同步动作 | {已同步到哪些文件} |
| 状态 | 已关闭 / 进行中 |
```

> 字段口径以 T3 变更管理规则为准，本模板只提供实例骨架。

---

## 当前不做什么

- 不把记忆系统的日常更新记为变更（记忆系统不算变更，见 T3）
- 不把变更日志与 decisions 混用（decisions 记决策，change_log 记变更流水）
- 不在模板中重写 T3 规则（规则只引用，不重复定义）
