# 框架演进记录（Evolution Log）模板

> 版本：v0.1.0
> 资产归类：产品资产 -> 标准模板
> 作用：定义每个项目的框架演进记录实例结构。Aida 按本模板 + [框架演进记录规则](../rules/框架演进记录规则_待确认.md) 生成项目级 `evolution_log.md`（建设资产）。
> 上级文档：[AidaPulse 白皮书 v0.1.0](../whitepaper/AidaPulse白皮书_待确认.md)

---

## 0. 模板定位

框架演进记录只记「有反哺项目价值」的演进节点（product 受限 / 补充机制 / 可推广 Skill / 里程碑），不做流水账。它是框架持续反哺自身的关键载体。

---

## 最小可用模板（占位符）

```md
# 框架演进记录 Evolution Log

> 记录规则、字段、触发时机见产品资产：{相对路径}/product/rules/框架演进记录规则_待确认.md。
> 本文件是本项目按规则产生的记录实例，与 change_log.md 平行。
> 资产归类：建设资产 -> 演进记录实例
```

## 记录字段口径

| 字段 | 说明 |
|------|------|
| 日期 | 记录时间 |
| 类型 | 里程碑 / product受限 / 补充机制 / 可推广Skill |
| 摘要 | 一句话说明演进内容 |
| 背景 | 为什么会有这次演进（触发原因、当时遇到的问题） |
| 关联 decision | 对应的 `decision-xxx`（如有） |
| 影响范围 | 影响到的 product 文档 / 能力 / 项目环节 |

> 类型枚举与触发时机见 [框架演进记录规则](../rules/框架演进记录规则_待确认.md)，本模板只提供实例骨架。

---

## 当前不做什么

- 不做流水账（只记三类有价值演进 + 里程碑）
- 不把演进记录并入 decisions.md（保持分工：decisions 细粒度、evolution_log 粗粒度索引）
- 不回溯补全历史里程碑（历史由项目自行决定，新记录从启用起结构化）
