# SIS：Markdown 同屏所见即所得

## 1. 任务目标

实现 Typora 式 Markdown 同屏所见即所得编辑：同一编辑视图内，文本按 Markdown 语义实时渲染为效果（标题/列表/表格/引用等），同时保持光标所在位置的完整源码可见、可编辑，无需切换到独立预览窗口。该能力是 aida-note"对标 Notepad++ 和 Typora 杂交体"的核心差异化之一。

- 必须完成：
  - 常用元素渲染全集：标题 / 加粗 / 斜体 / 删除线 / 行内代码 / 链接 / 图片 / 无序有序列表 / 引用 / 代码块（含 mermaid 围栏）/ 分隔线 / 表格
  - 光标所在行显示完整源码（含行内标记），光标移开后行内元素渲染为效果（A1 原则：行内标记隐藏、效果实时显示）
  - 段落级切换：以空行分隔的段落为最小渲染单元
  - 故障保护：语法不完整（未闭合标记 / 表格解析失败）时该处回退显示源码，不阻塞整体渲染
  - 性能：输入防抖 + 局部更新，不整文重渲染
- 建议完成：
  - 光标移入代码块/表格内部时的源码态与编辑态平滑过渡
- 当前不做：
  - 不做 mermaid 渲染效果（属 FUNC-4，本 SIS 仅负责 mermaid 代码围栏以源码形式展示）
  - 不做独立预览窗 / 双栏实时预览（PCB 反面教材：同屏所见即所得）
  - 不做大纲 / 目录侧栏（未列入 Backlog）
