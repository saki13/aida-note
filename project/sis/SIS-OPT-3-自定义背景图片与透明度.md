# SIS：自定义背景图片 + 透明度 / 对比度 / 色温

> 本 SIS 已于 2026-08-22 与 PO 对齐修订（双模式、三参数、工具栏/编辑区分区调节、按背景保存参数、替换图片、工具栏下拉入口）。

## 1. 任务目标

支持用户上传图片作为应用背景，实现个性化。背景默认关闭（未设置不显示）；设置后可灵活配置——**透明度 / 对比度 / 色温**三项参数，其中**对比度与色温按「工具栏区」与「编辑区」两块分开调节**；支持**双模式**（全应用 / 仅编辑区外）；参数**按背景图保存**（每张图记忆自己的主题参数）；支持**替换图片**与**清除背景**；任何设置都不得破坏文字可读性。

- 必须完成：
  - 入口：工具栏「背景」下拉（选择图片 / 替换图片 / 清除 / 模式切换 / 参数调节）
  - 背景渲染：图片铺为背景层；**模式 A 全应用**（整窗背景图，编辑区文字范围叠加遮罩保可读）；**模式 B 仅编辑区外**（文档文字范围保持纯色，文字区以外显示背景）
  - 三参数：透明度（全局，0-100%）、对比度（遮罩深浅，分工具栏区/编辑区两套）、色温（暖↔冷，分工具栏区/编辑区两套）
  - 分区调节：工具栏区（toolbar/tabbar/statusbar/chrome）与编辑区各自独立的对比度 + 色温参数
  - 按背景保存：每张背景图（以图片标识 key）记忆自己的一套参数；切换/替换图片时加载对应参数（无记录则用默认）
  - 替换图片：重新选择覆盖当前背景，参数保留（继承当前或该图已有记录）
  - 清除背景：恢复无背景（不影响其他设置）
  - 持久化：图片 + 模式 + 三参数入 settings（Tauri store + localStorage 兜底）
  - 明暗主题兼容：两主题下背景均正常显示
- 建议完成：
  - 背景图文件经 Tauri 对话框选择后复制到应用数据目录（防原路径失效）；浏览器环境用 localStorage dataURL 兜底
  - 图片路径失效时优雅降级（提示 + 自动清除），不阻塞应用
- 当前不做：
  - 不做多背景库 / 背景预览画廊 / 背景轮播动画
  - 不做图片裁剪 / 编辑（仅替换）

## 2. 人类意图

PO 原始表达（2026-08-22）：「可以上传图片来作为我们的背景，但是不要影响我们的工具的字体查看，要有透明度的配置，提高个性化的感觉」。修订对齐：「全应用与仅编辑区外两种模式可选项；手动设置对比度、透明度、色温；针对不同背景保存个性化主题；后续可编辑替换图片；工具栏和编辑区两块分开调色温和对比度」。

## 3. 输入 / 输出契约

- 输入：ARCH-2 settings 通道、Tauri plugin-dialog（选图）+ plugin-fs（复制/读取）、现有 data-theme 明暗体系
- 输出：
  - settings 字段：`background`（image / mode / opacity）+ `backgrounds`（按图 key 存参数 { chrome: {contrast, temperature}, editor: {contrast, temperature} }）入 AppSettings schema
  - 背景渲染层（工具栏区容器 + 编辑区容器各自 background-image + filter/遮罩）
  - 「背景」工具栏下拉（选图/替换/清除/模式/参数滑杆）
- 输出位置：`d:\lucia\workspace\aida-note\app\src\`（stores/settingsStore、services/settingsService、components/ToolBar.vue、views/MainView.vue、components/EditorPane.vue 等）

## 4. 边界与约束

- 可以改：色温/对比度的具体实现（CSS filter vs 遮罩 tint）、参数范围、下拉交互细节
- 不能改：
  - 默认无背景（未设置时不能改变现有观感）
  - 文字可读性保障（编辑区文字范围在任何模式/参数下必须可读）
  - 双模式语义（全应用 / 仅编辑区外-文字范围纯色）
- 必须遵守：
  - 参数按背景图保存（换图加载对应参数）
  - 持久化走 settings 通道，字段入 AppSettings schema
