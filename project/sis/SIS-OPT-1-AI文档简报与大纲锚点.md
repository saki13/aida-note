# SIS：AI 文档简报 + 大纲锚点

## 1. 任务目标

对当前文档调用 AI 生成「简报」（内容摘要）与「大纲」（标题结构列表），大纲项作为锚点可点击快速定位到文档对应位置。该功能依赖 AI API 配置（baseURL/key/model），**默认关闭**：未配置时不显示/不可用并提示，补充配置后自动开启。

- 必须完成：
  - 入口：工具栏「AI 简报」按钮（或 AI 面板内入口），点击对当前文档生成简报+大纲
  - 默认关闭：AI 未配置（aiConfig 任一字段为空）时入口禁用或点击提示「请先配置 AI API」
  - 简报：调用 AI 生成文档摘要，展示在侧栏/浮层（复用 aiService 通道）
  - 大纲：解析文档标题结构（Markdown `#/##/###` 及 `---` 分隔等）生成层级大纲；与 AI 简报在同一产出中展示
  - 锚点定位：点击大纲项 → 编辑器滚动到对应标题行并设置光标（复用 EditorPane 的滚动/光标能力）
  - 失败兜底：AI 调用失败提示且不破坏文档
- 建议完成：
  - 简报与大纲生成中 loading 态
  - 大纲支持多级缩进展示
- 当前不做：
  - 不做大纲的持久化 / 大纲面板常驻拖拽
  - 不做 AI 生成后可编辑回写文档（仅定位用）

## 2. 人类意图

PO 原始表达（2026-08-22）：「加载已有文档可以调用 ai 生成文档简报及大纲锚点，锚点可以快速定位，这个功能需要 api 信息，默认关闭，补充完信息可以开启」。

## 3. 输入 / 输出契约

- 输入：AI-1 的 aiService/aiStore 通道（OpenAI 兼容、非流式/流式封装）、当前文档内容（tabsStore.activeTab.content）、编辑器滚动/光标定位能力（EditorPane）
- 输出：
  - 简报 + 大纲展示组件（侧栏浮层或弹窗）
  - 大纲锚点 → 编辑器定位逻辑
  - 入口（工具栏按钮）+ 未配置提示
- 输出位置：`d:\lucia\workspace\aida-note\app\src\`（components/*、stores/aiStore、services/aiService）

## 4. 边界与约束

- 可以改：简报/大纲的展示形式（侧栏/弹窗）、AI prompt 措辞、大纲解析规则细节
- 不能改：
  - 默认关闭语义：未配置 API 时不可用并提示（不能默认联网调用）
  - 复用现有 aiConfig 配置（不新建配置体系）
- 必须遵守：
  - 锚点定位必须真实移动编辑器滚动/光标（不能只是视觉高亮）
  - AI 调用失败不得破坏文档内容
  - 自测采用 mock 响应（page.route 拦截），真实调用列 PO 验证（沿用 AI-1 沙箱对策）

## 5. 验收标准

- [ ] 未配置 AI API 时，「AI 简报」入口不可用且提示配置（Playwright）
- [ ] 配置 API 后入口可用，点击生成简报与大纲（mock 流式/非流式响应，Playwright）
- [ ] 简报展示文档摘要内容（mock 文本可见）
- [ ] 大纲项与文档标题一一对应（层级正确）
- [ ] 点击大纲锚点，编辑器滚动到对应标题行且光标定位（Playwright 断言滚动位置/光标）
- [ ] AI 调用失败（mock 500/超时）提示错误且文档内容不变
- [ ] `npm run build` 通过，不回归既有功能（含 ai-smoke/ai-mermaid-smoke）
