# SIS：mermaid 编写 + 原位实时渲染

## 1. 任务目标

实现 mermaid 图表在编辑器内**原位**实时渲染：mermaid 代码块在光标移出后自动渲染为图表，光标进入时显示完整源码可编辑，无需切换到独立预览窗口。这是 aida-note"mermaid 所见即所得"的核心差异化能力，也是 AI-1「mermaid 修复」的落点基础。

- 必须完成：
  - 防抖自动渲染：输入停顿后自动出图（与 FUNC-3 防抖节奏一致）
  - 编辑切换：光标进入代码块 → 显示完整源码可编辑；移出 → 渲染为图（与 FUNC-3 A1 原则一致）
  - 失败处理：mermaid 语法错误时显示可展开错误提示 + 回退源码，不阻塞整体
  - 图交互：只读展示 + 缩放查看 + 导出 SVG/PNG
  - 与 FUNC-3 协同：代码块（mermaid 围栏）在 FUNC-3 中作为源码展示，本 SIS 将其升级为原位渲染
- 建议完成：
  - 「AI 修复」入口占位（按钮/菜单，触发逻辑归 AI-1；本 SIS 仅预留 UI 入口与数据传递约定）
- 当前不做：
  - 不做 mermaid 之外的图表类型（如 Graphviz / PlantUML）
  - 不做独立预览窗口 / 双栏图表预览（PCB 反面教材：原位所见即所得）
  - 不做图内元素点击编辑 / 拖拽连线（编辑器内只读展示）

## 2. 人类意图

PO 原始表达（2026-08-20 逐项问答确认，FUNC-4 全部"照推荐"）：

- 防抖自动渲染：输入停顿后自动出图，所见即所得
- 光标进入即源码态：光标移入代码块显示源码可编辑，移出渲染为图（与 FUNC-3 A1 原则一致）
- 错误提示 + 回退源码：语法错误时显示可展开错误信息，同时回退源码
- 只读 + 缩放 + 导出：可缩放查看，可导出 SVG/PNG；不做编辑器内复杂交互

## 3. 输入 / 输出契约

- 输入：
  - ENV-2 依赖（mermaid.js）
  - FUNC-3（Markdown 同屏所见即所得，mermaid 代码围栏源码态已就绪）
  - UI-3 视觉设计（渲染态样式与明暗主题联动）
  - AI-1 约定（「AI 修复」入口的数据传递契约，若实现建议项）
- 输出：
  - mermaid 原位渲染实现代码（源码态 ↔ 渲染态切换 + 防抖渲染 + 失败回退 + 缩放/导出）
  - 「AI 修复」入口占位（建议项）
- 输出位置：`d:\lucia\workspace\aida-note\app\`（src/services、src/components）

## 4. 边界与约束

- 可以改：渲染实现方式、防抖阈值、缩放交互细节、导出格式细节
- 不能改：
  - 原位渲染（不做独立预览窗 / 双栏预览）
  - 防抖自动渲染（不做手动按钮触发）
  - 光标进入即源码态（不做点击/按钮切换）
  - 失败处理：错误提示 + 回退源码
  - 图交互：只读 + 缩放 + 导出 SVG/PNG
  - 仅支持 mermaid（不做其他图表类型）
- 必须遵守：
  - 与 FUNC-3 代码块渲染协同（同一代码块从源码态升级为渲染态，不冲突）
  - 渲染态样式随 UI-3 明暗主题联动
  - 导出不引入重依赖（用 mermaid 自带的 SVG 输出 + 浏览器下载）
  - 「AI 修复」入口仅占位，逻辑归 AI-1（本 SIS 不实现 AI 调用）
