# SIS：多标签文件编辑

## 1. 任务目标

实现 aida-note 编辑器的核心文件编辑能力：多标签管理（新建 / 打开 / 保存 / 另存为 / 关闭）、脏标记确认、撤销重做与语言识别，是编辑器的基础功能闭环。

- 必须完成：
  - 多标签：点击切换 / 关闭（含 dirty 确认）/ 新建 / 打开（对话框 + 拖拽）/ 保存 / 另存为
  - 脏标记：内容变更立即置位（圆点显示），关闭标签/窗口时 dirty 确认（保存/不保存/取消）
  - 撤销/重做：文档级历史，保存不清空，切换标签保留
  - 语言识别：按扩展名/内容自动识别（html/sql/js/json/markdown/纯文本）
  - 新建文件：未命名标签，首次保存触发另存为
- 建议完成：
  - 标签右键菜单（关闭/关闭其他/另存为）——UI-1 已定义，纳入本 SIS
  - 标签超宽滚动
- 当前不做：
  - 不做语法高亮（属 FUNC-2）
  - 不做自动保存/崩溃恢复（属 FUNC-10，P1）
  - 不做最近文件（属 FUNC-11，P1）

## 2. 人类意图

PO 原始表达（2026-08-19 逐项问答确认，FUNC-1 全部"照推荐"）：

- 撤销/重做：文档级历史，保存不清空，切换标签保留
- 新建：未命名标签（"未命名 N"），首次 Ctrl+S 触发另存为；语言按扩展名/内容自动识别，无扩展名默认纯文本
- 关闭：有 dirty 确认（保存/不保存/取消），无 dirty 直接关；关窗口时对所有 dirty 标签确认
- 打开：系统对话框（可多选）+ 拖拽文件到窗口打开

## 3. 输入 / 输出契约

- 输入：
  - ARCH-2 状态架构（tabsStore / Tab 模型 / 脏标记策略）
  - UI-1 布局（标签栏 / 工具栏功能 1-5）
  - ENV-1 目录结构（services/fileService、stores/tabsStore）
- 输出：
  - 功能代码：tabsStore 实现、fileService 实现（插件调用封装）、标签栏组件、dirty 确认逻辑、撤销重做接入、语言识别工具
  - 交付时 `npm run dev` 可手动验证上述交互
- 输出位置：`d:\lucia\workspace\aida-note\app\`（src/stores、src/services、src/components、src/views）

## 4. 边界与约束

- 可以改：具体实现细节（组件拆分方式、store 内部方法命名）
- 不能改：
  - 撤销/重做：保存不清空、切标签保留
  - 新建：未命名标签 + 首存另存为
  - 关闭：dirty 确认三选项
  - 打开：对话框多选 + 拖拽
  - 语言识别默认：无扩展名 → 纯文本
- 必须遵守：
  - 文件读写走 Tauri 官方插件（ARCH-1 职责划分）
  - 状态单一来源 tabsStore（ARCH-2）
  - UTF-8 + BOM 检测（ARCH-2 编码契约）
  - 不引入 vue-router

## 5. 验收标准

- [ ] 新建 → 出现"未命名 N"标签，首次保存弹出另存为对话框
- [ ] 打开 → 系统对话框可多选文件，多文件依次开标签；拖拽文件可打开
- [ ] 保存/另存为 → 文件写入成功，内容与磁盘一致（UTF-8）
- [ ] 脏标记 → 编辑后标签出现脏标记圆点，关闭时弹确认（保存/不保存/取消）三选项均生效
- [ ] 关窗口 → 存在 dirty 标签时弹确认，不静默丢失
- [ ] 撤销/重做 → 编辑后可撤销/重做；保存后历史保留；切换标签回来历史仍在
- [ ] 语言识别 → 按扩展名识别 html/sql/js/json/markdown，无扩展名识别为纯文本
- [ ] 标签交互 → 点击切换 / 关闭按钮 / 右键菜单（关闭/关闭其他/另存为）/ 超宽可滚动
- [ ] `npm run dev` 全流程可手动验证，`npm run build` 通过
