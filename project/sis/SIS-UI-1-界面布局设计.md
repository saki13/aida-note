# SIS：界面布局设计

## 1. 任务目标

设计 aida-note 编辑器的主界面布局：经典三段式（工具栏 + 标签页 + 编辑主区 + 状态栏）+ 可折叠 AI 侧栏，明确工具栏功能清单并映射到 Backlog（防止实现时对不齐），作为 UI-2 与各 FUNC SIS 的布局依据。

- 必须完成：
  - 三段式布局：顶部工具栏 / 中部标签页 + 编辑主区 / 底部状态栏
  - 可折叠右侧 AI 面板（属 AI-1 的载体）
  - 视图模式切换：编辑视图 / 对比视图 / 设置视图（组件状态控制，无路由）
  - 完整标签交互（点击切换 / 关闭按钮 / 右键菜单 / 脏标记圆点 / 超宽滚动）
  - 工具栏功能清单 + Backlog 映射表
- 建议完成：
  - 标签拖拽排序
  - 状态栏显示：光标行列 / 编码 / 语法语言 / 软换行开关状态 / 缩放级别
- 当前不做：
  - 不实现任何代码（本 SIS 只产出布局设计）
  - 不做多窗口 / 分屏（PCB 反面教材）
  - 不做视觉配色细节（属 UI-3，P1）
