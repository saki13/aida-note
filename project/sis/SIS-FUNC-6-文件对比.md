# SIS：文件对比（双栏 diff + 剪贴板）

## 1. 任务目标

实现 aida-note 的文件对比能力：双栏并排展示两份文本差异，行级 + 字符级高亮增删，支持差异跳转与滚动联动，并支持在差异块上做轻量合并（接受左侧/右侧应用到另一侧）。对比源 = 两个独立文件 + 当前文件 vs 剪贴板。

- 必须完成：
  - 对比源选择：工具栏「对比」入口 → 弹窗选源（① 打开两个文件；② 当前文件 vs 剪贴板）
  - diff 引擎：jsdiff（ENV-2 已接入）
  - 差异粒度：行级 + 行内字符级高亮（VS Code / Typora 风格）
  - 双栏并排 + 滚动联动
  - 差异导航：上一处 / 下一处跳转 + 差异计数
  - 轻量合并：单个差异块提供「接受左 / 接受右」，把某侧内容应用到另一侧；合并结果写回对应文件并置脏标记
- 建议完成：
  - 对比视图关闭时若存在未落盘的合并结果，触发脏标记确认（复用 FUNC-1 关闭确认）
- 当前不做：
  - 不做历史版本对比（PCB 决策：往后放）
  - 不做多文件批量对比 / 三栏对比
  - 不做自动合并（算法级 merge 冲突消解）

## 2. 人类意图

PO 原始表达（2026-08-20 逐项问答确认，FUNC-6）：

- 菜单选源：工具栏「对比」按钮 → 弹窗选源（两个文件 / 当前文件 vs 剪贴板）
- 行级 + 字符级：差异高亮到行内字符级（精细定位）
- 可合并编辑：对比视图支持合并（差异块级「接受左 / 接受右」应用到另一侧）
- 跳转 + 计数 + 联动：上一处/下一处差异跳转 + 差异计数 + 双栏滚动联动

## 3. 输入 / 输出契约

- 输入：
  - ENV-2 依赖（jsdiff）
  - FUNC-1（文件读取、标签脏标记、关闭确认）
  - FUNC-2（语言识别，用于差异块语法着色）
  - 剪贴板读取能力（Tauri clipboard 或前端 API）
- 输出：
  - 对比服务实现（diffService：双源加载 → 行级+字符级 diff → 差异块生成 → 合并应用）
  - 对比视图组件（双栏 + 滚动联动 + 跳转 + 计数 + 合并按钮）
  - 对比源选择弹窗
- 输出位置：`d:\lucia\workspace\aida-note\app\`（src/services/diffService、src/components、src/views）

## 4. 边界与约束

- 可以改：diff 算法参数、高亮配色细节、合并交互的按钮位置
- 不能改：
  - 对比源范围：两个独立文件 + 当前文件 vs 剪贴板（不做历史版本）
  - 差异粒度：行级 + 字符级
  - 双栏并排 + 滚动联动 + 差异跳转 + 计数
  - 支持合并编辑（差异块级「接受左 / 接受右」）
- 必须遵守：
  - 合并结果写回对应文件标签并置脏标记，与 FUNC-1 脏标记/关闭确认衔接
  - 剪贴板对比：剪贴板内容作为只读一侧，合并仅能把剪贴板侧内容应用到文件侧（或反之，需明确方向）
  - 大文件对比不阻塞 UI（diff 计算可异步/分片）
  - 不做历史版本对比
