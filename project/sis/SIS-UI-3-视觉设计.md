# SIS：视觉设计

## 1. 任务目标

定义 aida-note 编辑器的视觉基调：明暗双主题、编辑区主题联动、图标方案与克制的品牌视觉，支撑 FUNC-9（主题切换）与整体 UI 的观感一致。

- 必须完成：
  - 明暗双主题方案（Naive UI light/dark + 跟随系统，设置可手动覆盖）
  - 编辑区（CodeMirror）主题随全局明暗联动
  - 图标方案采用 xicons（@vicons/ionicons5）
- 建议完成：
  - 应用图标（Tauri 窗口图标）
- 当前不做：
  - 不做多套自定义配色（MVP 仅明暗双主题，"多套配色"留作 FUNC-9 扩展空间）
  - 不自绘图标 / 不引入品牌字体与启动页

## 2. 人类意图

PO 原始表达（2026-08-19 逐项问答确认，UI-3 全部"照推荐"）：

- 明暗双主题 + 跟随系统，设置可手动覆盖
- 编辑区配色随全局主题联动，不单独维护多套
- 图标用 Naive UI 生态配套（xicons），不自绘
- 品牌视觉克制：仅应用图标 + 系统字体栈，不背品牌成本

## 3. 输入 / 输出契约

- 输入：
  - UI-1 布局设计、UI-2 交互设计
  - ENV-2 依赖接入（CodeMirror / Naive UI 接入属 UI-1 相关 SIS 范围）
  - PO 的 UI-3 决策（见人类意图）
- 输出：
  - 视觉设计文档（明暗主题定义、编辑区主题联动、图标方案、字体栈、应用图标约定）
- 输出位置：`d:\lucia\workspace\aida-note\app\docs\ui-visual.md`

## 4. 边界与约束

- 可以改：配色具体色值（明暗两套的细节）、字体栈写法
- 不能改：
  - 明暗双主题 + 跟随系统（默认）
  - 编辑区主题随全局联动
  - 图标用 xicons
  - 品牌克制（不引入品牌字体/启动页）
- 必须遵守：
  - 与 UI-1 / UI-2 布局与交互一致
  - 视觉设计可被 FUNC-9（主题切换）引用执行
