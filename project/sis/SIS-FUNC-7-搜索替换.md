# SIS：搜索 / 替换（当前文件）

## 1. 任务目标

实现 aida-note 在当前文件内的搜索与替换能力：Ctrl+F 唤起顶部浮动搜索框，支持区分大小写 / 全词匹配 / 正则三选项，高亮所有匹配并支持上一处/下一处跳转与计数，替换支持单次与全部，且均进撤销栈可回退。

- 必须完成：
  - 搜索 UI：Ctrl+F 唤起顶部浮动搜索框（VS Code 风格，临时覆盖不占常驻空间）
  - 搜索选项：区分大小写 + 全词匹配 + 正则表达式（三选项齐全）
  - 结果高亮：高亮所有匹配项
  - 导航：上一处 / 下一处跳转 + 匹配计数
  - 替换：单次替换 + 全部替换，均进撤销栈可 Ctrl+Z 回退
- 建议完成：
  - 无匹配时的空态提示（如「无结果」）
- 当前不做：
  - 不做跨文件全局搜索（PCB 反面教材）
  - 不做多文件批量替换
  - 不做搜索历史 / 预设

- 可以改：搜索框具体样式、快捷键细节、正则语法选项的开关形态
- 不能改：
  - 作用范围：仅当前文件（不做跨文件全局搜索）

  - 替换能力：单次 + 全部，均进撤销栈可撤销
