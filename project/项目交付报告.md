## 4. 使用说明（速览）

- **基础**：Ctrl+N/O/S/Shift+S（新建/打开/保存/另存为）；Ctrl+F 搜索替换；Ctrl+Shift+F 格式化。
- **Markdown**：光标块源码态 / 其余渲染态；mermaid 围栏块自动出图（点击进源码，工具条缩放/导出 SVG/PNG）。
- **AI**：工具栏「AI 面板」开问答侧栏（先选中文本再提问，回答可插入光标）；选中文本后右键或工具栏「AI 润色」四选（改写/润色/缩短/扩写），流式结果气泡可接受/放弃；mermaid 语法错误块点「AI 修复」或工具栏「修复 mermaid」。
- **主题**：工具栏「主题」下拉三态切换 + 强调色（蓝/绿/紫），重启记住。
- **最近文件 / 自动保存**：工具栏「最近」下拉；未保存内容防抖写草稿，崩溃重启可恢复（7 天 TTL 自动清理）。
- **设置文件**：Tauri 环境存 app config 目录 settings.json；浏览器调试模式存 localStorage（`aida-note-settings`）。
