## 一、范围确认（PO 输入）

PO 在 Sprint 6 交付后反馈三个问题，收敛为两个任务：

1. **AI 简报体验差**：弹窗随时关闭、无缓存、每次点开都重新调 API；希望右上角悬窗 + 缓存 + 刷新按钮 + 后台生成 + 可隐藏/关闭/再打开。
2. **缺「上次打开的文件」恢复**：像 notepad++ 一样，退出后重开恢复上次的文件标签。

Planning 三轮追问结论（PO 确认）：
- 简报缓存**仅当次会话**（重启清空）；但**按文件各存一份**（key=文件路径，切换标签显示对应文件简报）
- 上次标签恢复 = **已保存文件 + 未保存草稿合并**：启动弹一次「恢复上次会话」确认，已保存文件直接重开、未保存内容回填置脏

## 二、成员与 DoD

### 任务 1：OPT-5 AI 简报悬窗 + 会话缓存（建议顺序：先做）

| 项 | 内容 |
|----|------|
| 目标 | 简报从弹窗改为**右上角悬窗**；当次会话内按文件缓存；新增刷新按钮；生成中关闭不中断、后台完成写缓存 |
| 入口 | 工具栏「AI 简报」按钮（保留，悬窗关闭后从这里再打开）|
| 悬窗 | 右上角浮动面板：标题+文件名+刷新+收起（最小化为小图标）/关闭；可隐藏、可关闭、可再打开 |
| 缓存 | aiStore 内存缓存 `briefCache: Map<key, {summary, outline, status, ts}>`，key=filePath（未保存 tab 用 tab.id）|
| 切换文件 | 悬窗显示当前文件简报；有缓存直接展示，无缓存空态 + 生成按钮 |
| 生成中 | 关闭悬窗不 abort；完成写缓存；再打开显示缓存或继续 loading |
| 默认关闭 | 未配置 API：提示不生成；悬窗默认隐藏，入口按钮打开 |
| 验收 | 见 SIS-OPT-5（自测 opt5-brief-smoke）|

### 任务 2：OPT-6 上次文件标签恢复（会话恢复）

| 项 | 内容 |
|----|------|
| 目标 | 退出后重开恢复上次打开的文件标签（已保存文件重开 + 未保存内容回填），一次「恢复上次会话」确认 |

## 三、风险与对策

| 风险 | 对策 |
|------|------|
| 悬窗布局与背景分层/编辑器滚动冲突 | 悬窗绝对定位于 main-view 右上角，z-index 高于内容低于 Naive 浮层；现有 opt3 背景层不影响 |
| 会话快照与草稿机制语义冲突 | 快照=正常退出恢复；草稿=异常退出恢复；启动时快照优先，无快照才走草稿检查 |
| 生成中关闭的异步竞态 | aiStore 独立持有进行中请求（不随悬窗关闭 abort）；同文件重复生成先 abort 旧请求 |
| 恢复大量文件的加载时长 | 已保存文件逐个 readFile 串行打开，加载失败跳过并提示 |
