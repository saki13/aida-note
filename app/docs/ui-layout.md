# aida-note 界面布局设计（UI-1）

> 版本：v1.0 · 2026-08-20 · Sprint 2
> 依据：SIS-UI-1 / ARCH-1（`app/docs/architecture.md`）/ ARCH-2（`app/docs/state-architecture.md`）
> 定位：UI-2（交互）/ UI-3（视觉）与 FUNC 系列实现的布局依据。本文档只做设计，不含实现。
> UI 组件库：Naive UI（本文档仅做组件映射设计，组件落地属 FUNC-1 起）。

## 1. 主界面布局（三段式 + 可折叠 AI 侧栏）

```
┌──────────────────────────────────────────────────────────────────┐
│ ① 工具栏（顶部，固定高度，主操作区）                                │
│ [新建][打开][保存][另存为] | [撤销][重做] | [搜索][格式化][软换行]   │
│ [对比] | [主题][AI 面板] | [设置]                                  │
├──────────────────────────────────────────────────────────────────┤
│ ② 标签栏（标签页 + 超宽横向滚动）                                   │
│ [● a.md ×][app.vue ×][config.json ×] →→→（超出横向滚动）           │
├───────────────────────────────────────────────┬──────────────────┤
│                                               │ ④ AI 侧栏         │
│ ③ 编辑主区                                     │ （右侧可折叠，     │
│                                               │  默认收起，        │
│   - 编辑视图：CodeMirror 6                     │  AI-1 的载体）     │
│   - 对比视图：双栏 diff                         │                   │
│   - 设置视图：设置表单                          │                   │
│                                               │                   │
├───────────────────────────────────────────────┴──────────────────┤
│ ⑤ 状态栏（底部，固定高度，信息展示区）                              │
│ 行 x, 列 y | UTF-8 | Markdown | 换行:开 | 缩放 100%                │
└──────────────────────────────────────────────────────────────────┘
```

- 布局实现：单根 flex 纵向容器（①②⑤ 固定高度，③④ 占满剩余），③+④ 为横向 flex。无路由、无多窗口（ARCH-1 规则 5）。
- 五区与 ARCH-1 分层对应：①②⑤ = `components/`（ToolBar / TabBar / StatusBar），③ = `views/`（MainView / DiffView / SettingsView 编排），④ = `components/AiPanel`（属 AI-1 载体，Sprint 4 前仅占位折叠容器）。

### AI 侧栏（④）折叠规则

| 状态 | 行为 |
|------|------|
| 收起（默认） | 宽度 0，编辑主区占满；工具栏 [AI 面板] 按钮切换 |
| 展开 | 固定宽度 320px（可后续调整），编辑主区自适应压缩 |
| 载体归属 | AI-1（P1，Sprint 4）；本布局仅预留容器与开合状态 |

## 2. 视图模式切换（组件状态控制，无路由）

| 视图 | 内容 | 切换方式 | 状态归属 |
|------|------|---------|---------|
| 编辑视图（默认） | CodeMirror 6 编辑器 | 工具栏 [对比]/[设置] 退出；或关闭对比/设置时回到 | tabsStore 驱动 |
| 对比视图 | 双栏 diff（FUNC-6） | 工具栏 [文件对比] 进入 | ui 状态（`viewMode: 'edit' \| 'diff' \| 'settings'`，存于 tabsStore 或独立 uiStore，FUNC-1 实现时定） |
| 设置视图 | 设置表单（主题/软换行/AI 配置等，写 settingsStore） | 工具栏 [设置] 进入 |

- 切换语义：视图是**覆盖层态**而非页面导航（ARCH-1 规则 5：views 组件条件渲染）；标签栏与工具栏在三种视图下保持可见（设置视图下工具栏部分按钮禁用）。
- 编辑器内容不因视图切换丢失：切走再切回，CodeMirror doc 状态由 tabsStore 恢复（ARCH-2 §1 单一来源）。

## 3. 标签交互（完整）

| 交互 | 行为 | 依据 |
|------|------|------|
| 点击切换 | 激活该标签，编辑器装载其 content/language | tabsStore.setActive() |
| 关闭按钮（×） | 非 dirty 直接移除；dirty 弹三选确认（保存/不保存/取消） | ARCH-2 §2.2 |
| 右键菜单 | 关闭 / 关闭其他 / 关闭右侧 / 关闭全部（全部含 dirty 确认） | 本文新增，属 FUNC-1 实现项 |
| 脏标记圆点（●） | `tab.dirty` 为真时标题前显示圆点，保存/Ctrl+Z 复位后消失 | ARCH-2 §1.3 派生态 |
| 超宽滚动 | 标签总数超出宽度时横向滚动，激活标签自动滚入可见区 | - |
| 拖拽排序（建议项） | tabsStore.moveTab(from, to) 已预留签名 | ARCH-2 §1.2；非验收必需 |
| 新建标签 | 工具栏 [新建] / Ctrl+N，标题「未命名-N」 | ARCH-2 createUntitled() |

- 单一来源：标签顺序、激活态、脏标记全部读自 tabsStore，组件不私存副本（ARCH-2 §1 原则）。

## 4. 工具栏功能清单 + Backlog 映射（防对不齐）

| # | 工具栏功能 | 对应 Backlog | 优先级 | 备注 |
|---|-----------|-------------|--------|------|
| 1 | 新建文件 | FUNC-1（多标签编辑） | P0 | Ctrl+N |
| 2 | 打开文件 | FUNC-1 | P0 | Ctrl+O |
| 3 | 保存 | FUNC-1 | P0 | Ctrl+S；无 path 时转另存为 |
| 4 | 另存为 | FUNC-1 | P0 | Ctrl+Shift+S |
| 5 | 撤销 / 重做 | FUNC-1（CodeMirror 基础历史，纳入 FUNC-1 DoD） | P0 | Ctrl+Z / Ctrl+Y |
| 6 | 搜索 / 替换 | FUNC-7 | P0 | Ctrl+F / Ctrl+H |
| 7 | 格式化 | FUNC-5 | P0 | 4 语言，SQL 不做 |
| 8 | 软换行开关 | FUNC-8 | P0 | 全局共享设置 |
| 9 | 文件对比 | FUNC-6 | P0 | 进入对比视图 |
| 10 | 主题切换 | FUNC-9 | P1 | 三态 light/dark/system |
| 11 | AI 面板开关 | AI-1 | P1 | 侧栏开合 |
| 12 | 设置（打开设置视图） | ARCH-2 settingsStore + FUNC-9/FUNC-10 | P1 | 设置视图入口 |

> 映射核查结论：12 项功能全部有对应 Backlog Story，无缺项；撤销/重做归入 FUNC-1 DoD（SIS-UI-1 §4.1 原样继承）。

- 布局分组：文件组（1-4）/ 历史组（5）/ 编辑组（6-8）/ 视图组（9）/ 全局组（10-12），组间分隔线。
- 按钮状态联动：保存/另存为/格式化/搜索在无激活标签时禁用；主题按钮显示当前态。

## 5. 状态栏定义（信息齐全）

| 槽位 | 内容 | 数据来源 |
|------|------|---------|
| 光标位置 | 行 x, 列 y（1 起始） | CodeMirror selection（EditorView.updateListener） |
| 编码 | UTF-8（固定显示；读出非 UTF-8 时显示「非 UTF-8，可能乱码」） | fileService 读取结果（ARCH-2 §3.1） |
| 语法语言 | 当前标签 language（如 Markdown / JSON） | tab.language（FUNC-2 扩展名映射） |
| 软换行状态 | 换行:开 / 换行:关（可点击切换） | settingsStore.wordWrap（FUNC-8） |
| 缩放级别 | 缩放 100%（编辑器字号缩放，Ctrl+滚轮，可点击复位） | FUNC-1 实现项（编辑器基础能力） |

- 无激活标签时状态栏显示应用名/就绪态占位。

## 6. Naive UI 组件映射（设计引用）

| 界面区 | Naive UI 组件（候选） |
|--------|----------------------|
| 工具栏 | NButton / NButtonGroup / NDivider / NTooltip |
| 标签栏 | NTabs（或自绘 TabBar + NDropdown 右键菜单）--FUNC-1 实现时按 CodeMirror 集成度取舍 |
| 状态栏 | NText + 自定义布局 |
| AI 侧栏 | NDrawer / 自定义面板 |
| 关闭确认 | NDialog（三选：保存/不保存/取消） |
| 设置视图 | NForm / NSwitch / NSelect / NInput |

> 组件选型最终以 FUNC-1 实现为准；本文档锁定「用 Naive UI、不用其他组件库」这一约束。

## 7. 一致性核查（SIS-UI-1 验收第 7 项）

| 检查点 | 结论 |
|--------|------|
| 三段式 + 可折叠 AI 侧栏 | ✓ §1（工具栏/标签页+编辑主区/状态栏 + 右侧折叠面板） |
| 三种视图模式切换（无路由） | ✓ §2（组件状态条件渲染，ARCH-1 规则 5 一致） |
| 完整标签交互 | ✓ §3（切换/关闭/右键菜单/脏圆点/超宽滚动，拖拽为建议项） |
| 工具栏清单 + Backlog 映射无缺项 | ✓ §4（12/12 有 Story） |
| 状态栏内容齐全 | ✓ §5（行列/编码/语言/软换行/缩放） |
| 与 ARCH-1 一致 | ✓ 五区映射 components/views 分层；视图切换机制复用其规则 5；工具栏不直接调 service |
| 与 ARCH-2 一致 | ✓ 标签交互全部落到 tabsStore 动作签名（setActive/closeTab/moveTab/createUntitled）；脏圆点=§1.3 派生态；关闭确认=§2.2 三选 |
