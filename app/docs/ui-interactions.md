# aida-note 交互设计（UI-2）

> 版本：v1.0 · 2026-08-21 · Sprint 2
> 依据：SIS-UI-2 / UI-1（`app/docs/ui-layout.md`）/ ARCH-1（`app/docs/architecture.md`）/ ARCH-2（`app/docs/state-architecture.md`）
> 定位：FUNC-3（所见即所得）/ FUNC-4（mermaid）/ FUNC-6（对比）/ AI-1 的交互实现依据。本文档只做交互设计，不含实现与视觉细节（视觉属 UI-3）。
> 核心原则（PO 定案，不可改）：光标行内标记隐藏（Typora 式）/ mermaid 原位渲染 + 点击进编辑 + 修复入口 / AI 润色现场化 + 问答侧栏化 / 对比双栏 + 滚动联动 + 差异跳转。

## 1. 所见即所得编辑交互（Typora 式同屏）— FUNC-3 依据

### 1.1 核心机制：块级源码/渲染双态

CodeMirror 6 编辑器内同一文档按「块」（block：段落/标题/列表项/代码块/引用/表格行）划分，每块处于两种形态之一：

| 形态 | 表现 | 触发条件 |
|------|------|---------|
| **源码态** | 显示原始 Markdown 标记（`#`、`**`、`` ` `` 等），等宽字体 | 光标（或选区）位于该块内 |
| **渲染态** | 隐藏标记、显示效果（标题放大加粗、粗体、斜体、行内代码底纹、链接着色、删除线等），保持**可编辑**（点击即进入） | 光标不在该块内 |

- 状态切换粒度 = **块级**（不是整行整篇）：光标进入哪块，哪块显示源码；其余块保持渲染。
- 光标移出（点击别处 / 方向键跨块）-> 该块**立即**恢复渲染态（无需防抖，切换本身无异步开销）。
- 选区横跨多块时：选区覆盖的所有块显示源码（保证复制/编辑源码的一致性）。

### 1.2 行内元素规则（光标所在块内的例外）

光标所在块显示源码，但**空标记对**（如 `****`、`||`）仍原样显示以方便输入。已配对的行内标记（`**加粗**`）在光标位于其内部时显示标记本身。

### 1.3 实现路径（CM6 decorations）

- 基于 `@codemirror/lang-markdown` + 自定义 decoration 插件（WidgetDecoration 渲染行内效果 + MarkDecoration 隐藏标记），光标块判定由 `EditorSelection` 与块 range 求交驱动。
- **仅 `language === 'markdown'` 的标签启用**（FUNC-2 语言体系内判断）；其他语言（js/json/html/sql/plaintext）编辑行为不变。
- 扩展挂载走 FUNC-2 已建立的 Compartment 槽位机制（语言切换时 reconfigure），EditorState 存 store 必须 `markRaw()`（decision-013 原则）。

### 1.4 状态与边界

| 场景 | 规则 |
|------|------|
| 纯文本/非 markdown 标签 | 不启用所见即所得，保持普通编辑 |
| 源码模式开关 | 不提供（v1 不做「纯源码模式」切换，Typora 式即默认且唯一形态） |
| 撤销/重做 | CM6 history 原生支持，形态切换不产生历史记录项 |
| 与软换行（FUNC-8）正交 | 软换行只影响显示折行，不影响双态机制 |
| 与搜索（FUNC-7）联动 | 搜索命中高亮在渲染态块上仍可见（命中处临时显示源码背景标记） |

## 2. mermaid 块交互（原位渲染）— FUNC-4 依据

### 2.1 核心机制：代码块双态 + 原位替换渲染

markdown 文档中 ` ```mermaid ` 围栏代码块采用与 §1 同款的块级双态，但渲染态为**图表**：

```
┌─ 源码态（光标在块内）────────┐   ┌─ 渲染态（光标在块外）────────┐
│ ```mermaid                 │   │ ┌───────────────────────┐   │
│ graph TD; A-->B;           │   │ │   [mermaid SVG 原位]   │   │
│ ```                        │   │ │   宽度 = 编辑区内容宽   │   │
└────────────────────────────┘   │ └───────────────────────┘   │
                                  └────────────────────────────┘
```

| 交互 | 行为 |
|------|------|
| 点击渲染态图表 | 图表切换回源码态，光标置于点击处对应行（v1 置块首），可直接编辑 |
| 光标移出代码块 | 防抖 300ms 后重新渲染为图（编辑过程中不反复渲染） |
| 源码变更 | 同上，离开块时才重渲染（渲染是离开触发的，不是输入触发的） |
| 渲染成功 | mermaid SVG 原位替换显示，横向超出可滚动（v1 不做缩放，滚动足够） |
| 渲染失败 | 显示错误占位框：错误信息摘要 + **[AI 修复]** 按钮（见 §2.2）+ **[编辑源码]** 按钮 |

### 2.2 修复入口（衔接 AI-1）

- 渲染失败占位框上的 [AI 修复]：将出错源码交 `aiService`（mermaid 修复能力）-> 返回修复后源码 -> **以 diff 预览形式展示**（复用 §5 对比的行内 diff 展示）-> 用户 [应用] 后替换代码块内容（进 CM6 history，可 Ctrl+Z 撤销）。
- AI 未配置（settingsStore.aiConfig 为空）时：[AI 修复] 点击 -> 提示「未配置 API，去设置」-> 跳设置视图。

### 2.3 实现路径与边界

- mermaid 11 前端渲染（`mermaid.render`），渲染节点 DOM 归编辑器组件持有（ARCH-1 规则 4 同款生命周期原则）；渲染为异步，进行中显示轻量 loading 占位。
- **只对 ```mermaid 围栏块生效**；普通 ``` 代码块维持源码展示（FUNC-3 §1.3 行内代码底纹即可）。
- 非 markdown 标签中不出现 mermaid 块（语言体系外）。

## 3. AI 润色交互（选中文本现场触发）— AI-1 依据

### 3.1 触发与四动作

```
选中文本 ──> 光标旁浮出操作条（浮动菜单，不弹对话框）
             [改写] [润色] [缩短] [扩写]  ×（收起）
```

| 规则 | 说明 |
|------|------|
| 触发 | 编辑器内有非空选区即浮出操作条（跟随选区尾端，滚动/取消选区则消失） |
| 四动作 | 改写（通用重写）/ 润色（保持原意优化表达）/ 缩短 / 扩写；对应 aiService 四个 prompt 模板 |
| 上下文 | 请求携带选中文本 + 所在文档语言（markdown 优先保持标记完整） |
| loading | 动作点击后操作条变为 loading 态（保留 × 取消），请求期间选区锁定提示（选区高亮保持） |
| 失败 | 操作条内联显示错误摘要 + [重试]；不弹全局错误框 |

### 3.2 结果展示与接受/撤销

```
响应返回 ──> 选区下方浮出结果气泡：
             ┌──────────────────────────────┐
             │ 结果文本（与原文 diff 高亮：    │
             │  新增=绿底/删除=红底删除线，    │
             │  行内字符级，jsdiff）          │
             │ [接受] [放弃]                  │
             └──────────────────────────────┘
```

| 规则 | 说明 |
|------|------|
| diff 高亮 | 可选项（建议项，默认开）：aiService 返回纯文本后本地 jsdiff 字符级计算，气泡内高亮展示改动 |
| 接受 | 结果文本**替换**原选区（一次 CM6 transaction，进 history）；气泡关闭 |
| 放弃 | 气泡关闭，原文不动 |
| 撤销 | 接受后 Ctrl+Z 由 CM6 history 原生恢复（不另建撤销栈，单一路径） |
| 请求中切走标签 | 请求继续但结果气泡随选区上下文失效而丢弃（v1 不跨标签挂起结果） |

## 4. AI 问答交互（侧栏聊天）— AI-1 依据

### 4.1 侧栏形态（UI-1 §1 ④ 的展开态）

| 规则 | 说明 |
|------|------|
| 开合 | 工具栏 [AI 面板] 切换，展开宽 320px（UI-1 既定），默认收起 |
| 结构 | 单列聊天流：用户消息（右对齐气泡）/ AI 回答（左对齐，Markdown 渲染显示）+ 底部输入框（多行，Enter 发送 / Shift+Enter 换行） |
| 会话归属 | 会话历史属于 aiStore（ARCH-1 三 Store 之一）；v1 单会话（不建多会话列表），随应用生命周期，不持久化 |
| 流式 | SSE 流式逐字上屏（aiService fetch 流式）；流式中输入框禁用发送，显示 [停止] |
| 未配置 | 面板顶部常驻提示条「未配置 API」+ [去设置] 按钮 |

### 4.2 回答一键插入光标处

| 规则 | 说明 |
|------|------|
| 插入按钮 | 每条 AI 回答气泡下方常驻 [插入到光标处]（流式结束后出现） |
| 插入行为 | 回答全文插入**当前激活标签**的编辑器光标位置（一次 transaction，进 history）；若光标处已有选区则替换选区 |
| 目标失效 | 无激活标签时按钮禁用；插入瞬间标签被关闭（极端）则静默失败并 toast 提示 |
| 换行语义 | 回答文本按原样插入（含换行）；markdown 标记原样保留（所见即所得态自动生效展示） |

### 4.3 与润色的关系

润色（§3）走选区现场触发，**不经过**问答侧栏；两者共用 aiService 与 aiConfig，UI 上独立。mermaid 修复（§2.2）亦不经侧栏。

## 5. 对比视图交互（双栏 diff）— FUNC-6 依据

### 5.1 进入流程与对比源

工具栏 [对比] -> 进入对比视图（UI-1 §2 的 viewMode 切换，覆盖层态）-> 先选对比源：

| 对比源 | 入口流程 |
|--------|---------|
| 两个独立文件 | 选源 A（文件对话框）-> 选源 B -> 开始对比 |
| 当前文件 vs 剪贴板 | 直接读取激活标签内容 + 剪贴板文本 -> 开始对比 |

- 选源阶段显示轻量引导面板（两栏占位 + [选择文件] / [使用剪贴板] 按钮）；取消则退回编辑视图。
- 剪贴板对比要求存在激活标签，否则该入口禁用。

### 5.2 对比视图布局与滚动联动

```
┌─ 对比视图 ──────────────────────────────────────────────┐
│ [A: 文件名/剪贴板]              [B: 文件名/当前标签名]    │
│ ┌──────────────────┐  ↑↓   ┌──────────────────┐        │
│ │ 左栏（源 A，只读） │ 差异  │ 右栏（源 B，只读） │        │
│ │ 行级 diff 高亮     │ 跳转  │ 行级 diff 高亮     │        │
│ └──────────────────┘  条   └──────────────────┘        │
│ 底部：[← 上一个差异 (2/5)] [下一个差异 →] [退出对比]       │
└─────────────────────────────────────────────────────────┘
```

| 规则 | 说明 |
|------|------|
| 双栏并排 | 左右 50/50，均只读（对比是查看型功能，v1 不做栏内编辑与合并） |
| diff 粒度 | 行级块（jsdiff diffLines）+ 行内字符级高亮（diffChars，行内改动着重色），与 §3.2 润色 diff 同一展示逻辑复用 |
| 高亮语义 | A 栏：删除行红底；B 栏：新增行绿底；行内变更字符级加重 |
| 同步滚动 | 两栏滚动按**行偏移对齐联动**（A 滚到第 n 行，B 同步滚到对应对齐行；diff 块使两栏行号存在错位，联动按 diff 映射表换算）；v1 不提供解除联动开关 |
| 差异跳转 | 底部 [上一个]/[下一个] 按差差异块序跳转（滚动定位 + 短暂高亮闪烁）；计数显示 (当前/总数) |
| 退出 | [退出对比] 或工具栏 [对比] 再点 -> 回编辑视图，标签内容状态不受影响（ARCH-2 单一来源） |

### 5.3 状态与边界

| 场景 | 规则 |
|------|------|
| 视图切换时机 | 对比进行中切走（点设置等）-> 对比结果保留于视图状态，切回可继续（v1 不做后台重算） |
| 无激活标签 | 「当前文件 vs 剪贴板」入口禁用；两独立文件对比不受影响 |
| 大文件 | diff 计算在前端同步执行，>2MB 文件提示确认后再算（防卡顿，不做虚拟滚动，超出范围） |
| 编码 | 两源均按 fileService 读取契约（UTF-8 + BOM 剥离，ARCH-2 §3.1） |

## 6. 交互资产与依赖映射（实现指引）

| 交互链路 | 实现 Story | 状态来源 | 服务 | 组件落点 |
|---------|-----------|---------|------|---------|
| 所见即所得 | FUNC-3 | tabsStore（language 判定） | - | EditorPane（CM6 扩展） |
| mermaid 块 | FUNC-4 | tabsStore | aiService（修复） | EditorPane（块 Widget） |
| AI 润色 | AI-1 | tabsStore（选区） | aiService | EditorPane（浮动 UI） |
| AI 问答 | AI-1 | aiStore | aiService | AiPanel（侧栏） |
| 对比 | FUNC-6 | tabsStore + ui viewMode | diffService / fileService | DiffView |

- 全部链路遵守 ARCH-1 依赖方向：components 不直调 service（经 store）；CodeMirror/mermaid DOM 实例归组件持有。
- Naive UI 组件映射（UI-1 §6 延伸）：浮动操作条 = NPopover / NButton；结果气泡 = NCard + 自定义 diff 视图；AI 侧栏 = 自定义面板 + NInput；对比视图 = 自绘双栏（NButton 跳转条）。
